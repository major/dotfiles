# Glossary

**Applicative order** — evaluate call arguments before entering the function (Ch 2, Ch 5).

**Asyncio** — standard-library framework for coordinating awaitable asynchronous operations (Ch 5, Ch 9).

**Closure** — function retaining bindings from an enclosing scope (Ch 5).

**Context manager** — protocol governing setup and cleanup around `with` (Ch 3, Ch 4).

**Copy** — shallow copy duplicates a container boundary; deep copy recursively duplicates contained objects (Ch 4).

**Descriptor** — object controlling attribute access through descriptor methods (Ch 7).

**Garbage collection** — reclamation of unreachable objects, including cyclic references (Ch 4).

**Encoding** — conversion of Unicode text to bytes (Ch 9).

**Generator** — suspended function object driven by iteration or `next()` (Ch 6).

**Identity** — unique identity distinguishable with `is` (Ch 4).

**Iterable** — object capable of supplying successive values (Ch 1, Ch 2, Ch 6).

**Mixin** — focused cooperative class that adds behavior (Ch 7).

**Introspection** — examining runtime functions, signatures, attributes, and environments (Ch 5, Ch 10).

**Module** — executable namespace loaded by `import` (Ch 1, Ch 8).

**MRO** — method resolution order for class attribute lookup (Ch 7).

**Polling** — repeatedly checking readiness or state without blocking the controlling loop (Ch 9).

**Protocol** — expected operations and special methods for a behavior (Ch 4, Ch 7).

**Serialization** — representation of objects for storage or exchange (Ch 9).

**Slots** — `__slots__` declaration that can reduce instance memory while restricting attributes (Ch 7).

**Text** — Unicode `str`, distinct from raw `bytes` (Ch 9).

**Weak reference** — reference that does not keep its target alive (Ch 7).

**Yield** — suspends a generator and produces a value (Ch 6).

**Zero-copy I/O** — using `readinto(preallocated_buffer)` to fill a contiguous preallocated destination buffer (Ch 9).

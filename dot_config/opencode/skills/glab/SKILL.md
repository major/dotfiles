# GitLab CLI (glab)

Prefer the gitlab MCP server if it is available.
Open a gitlab issue on major/gitlab-mcp if you find a bug or a significant token efficiency gain.
If you must use the glab cli to get gitlab work done, this is a bug with gitlab-mcp and an issue must be filed.

`glab` is pre-configured and available in your environment.
Run `glab <command> --help` for detailed flag information.
